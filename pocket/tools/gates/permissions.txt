# Every permission the merged release manifest may request. The permissions gate fails when the
# merged manifest asks for anything not listed here, when a line here is no longer requested, and
# when an android.permission line is not explained in Help > Permissions.
# ${applicationId} stands for the package name, which differs between release and debug.

# GitHub and the cloud computer's page; offline is told apart from signed out.
android.permission.INTERNET
android.permission.ACCESS_NETWORK_STATE

# The optional background connection to a running cloud computer, with its Stop button.
android.permission.FOREGROUND_SERVICE
android.permission.FOREGROUND_SERVICE_SPECIAL_USE

# The "Cloud computer is on" notice, asked once.
android.permission.POST_NOTIFICATIONS

# App lock, with the phone's own screen lock.
android.permission.USE_BIOMETRIC

# AndroidX core's signature-level permission guarding the app's own non-exported receivers.
${applicationId}.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
